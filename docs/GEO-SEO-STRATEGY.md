## Core GEO Principles

### What is GEO (Generative Engine Optimization)?
The practice of optimizing content to appear in AI-powered answers rather than traditional SERPs, focusing on making content understood, trusted, and referenced by AI systems.

### Key Success Factors
1. **30-40% visibility increase** from including quotes, statistics, and citations
2. **Structured content** with clear hierarchies
3. **Direct answers** to user questions
4. **Verifiable sources** (LLMs check these!)
5. **Entity authority** in Google Knowledge Graph

## Content Structure Requirements

### ✅ CRITICAL: Hierarchical Heading Structure

```markdown
# [H1: Question-Based Title]

## [H2: Quick Answer or Major Section]
[Direct, concise answer in first 2-3 sentences]

### [H3: Subsection Detail]
[Detailed explanation with citations]

### [H3: Another Subsection]
[More specific information]

## [H2: Evidence & Research]
[Academic backing with proper citations]

## [H2: Actionable Takeaways]
[Practical recommendations]

## References
[Properly formatted academic citations]
```

### ✅ Opening Paragraph Formula
1. **Shocking statistic** or compelling data point
2. **Source citation** within first paragraph
3. **Direct answer** to title question
4. **2-3 sentences maximum** before first H2

**Example:**
> "Traditional science laboratories are responsible for 60-65% of a university's total energy consumption and produce an estimated 5.5 million tonnes of plastic waste annually (Urbinati et al., 2024). This environmental crisis demands innovative solutions that maintain educational quality while dramatically reducing impact."

### ✅ Required Elements per Article

**Minimum Requirements:**
- [ ] 5-10 academic citations (properly formatted)
- [ ] Clear H2/H3 structure (3+ H2 sections minimum)
- [ ] Statistics/data points in first paragraph
- [ ] Direct answers to implicit questions
- [ ] Concrete examples or case studies
- [ ] Properly formatted References section

**Optimal Requirements:**
- [ ] 8-15 academic citations
- [ ] Question-based H2 headings ("How Does...", "What Are...", "Why Is...")
- [ ] Multiple statistics per section
- [ ] Real-world examples with specifics
- [ ] Cross-links to other WhimsyLabs content
- [ ] Structured data markup (Schema.org)

## Citation & Authority Guidelines

### Academic Citation Standards

**Format:**
```jsx
(
  <a
    href="[DIRECT_LINK_TO_SOURCE]"
    target="_blank"
    rel="noopener noreferrer"
  >
    Author et al., Year
  </a>
)
```

**Best Practices:**
1. **Use primary sources** when possible
2. **Verify all URLs** - LLMs check these
3. **Recent citations** (2020+) preferred for credibility
4. **Mix source types:**
   - Academic journals (highest authority)
   - Government/institutional reports
   - Industry research
   - Reputable news sources

**Red Flags to Avoid:**
- ❌ Broken links
- ❌ Fabricated citations
- ❌ Self-citations without external validation
- ❌ Non-authoritative sources for key claims

### References Section Format

```jsx
<div className="references-section">
  <h3>References</h3>
  <ul className="references-list">
    <li key="ref-1">
      Author, A., Author, B., & Author, C. (Year). Title of work.
      <em>Journal/Publication Name</em>, Volume(Issue), Pages.
    </li>
    {/* More references... */}
  </ul>
</div>
```

## Technical Implementation

### MPA (Multi-Page Application) Optimization

#### HTML Export Requirements
```html
<!-- Each page must include: -->
<head>
  <title>[Specific Page Title] | WhimsyLabs Blog</title>
  <meta name="description" content="[Unique meta description 150-160 chars]">

  <!-- Open Graph -->
  <meta property="og:title" content="[Page Title]">
  <meta property="og:description" content="[Description]">
  <meta property="og:url" content="https://whimsylabs.ai/blog/[slug]/">
  <meta property="og:type" content="article">
  <meta property="article:published_time" content="[ISO Date]">

  <!-- Structured Data -->
  <script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "BlogPosting",
    "headline": "[Title]",
    "datePublished": "[ISO Date]",
    "author": {
      "@type": "Organization",
      "name": "WhimsyLabs"
    },
    "publisher": {
      "@type": "Organization",
      "name": "WhimsyLabs",
      "logo": {
        "@type": "ImageObject",
        "url": "https://whimsylabs.ai/logo.png"
      }
    }
  }
  </script>
</head>
```

#### URL Structure
```
✅ Good: /blog/[slug]/
✅ Good: /en/blog/[slug]/
❌ Bad: /blog?post=[slug]
❌ Bad: /blog#[slug]
```

#### Internal Linking Strategy
```jsx
// Cross-link between related posts
<a href="/blog/physicality-in-virtual-labs/">
  Our approach to physicality in virtual labs
</a>

// Link to product pages
<a href="https://whimsylabs.ai/contact/">
  Join our pilot program
</a>
```

### Image Optimization
```jsx
<img
  src="/images/[filename].jpg"
  alt="[Descriptive alt text for accessibility and SEO]"
  className="rounded shadow center limited-size"
  loading="lazy"
/>
<p className="caption">
  [Detailed image caption with context]
</p>
```

**Alt Text Best Practices:**
- ✅ Descriptive and specific
- ✅ Include relevant keywords naturally
- ✅ Explain what's shown and why it matters
- ❌ Keyword stuffing
- ❌ "Image of..." (screen readers say this already)
