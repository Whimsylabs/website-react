🛡️ プライバシーファースト設計

生徒のデータ。あなたの管理下に。

当社のvirtual labソフトウェアはプライバシーを核に構築。貴校のデータは保護され、暗号化され、あなたの管理下に置かれます。

セキュリティへの取り組み

🔐

多要素認証

管理者アカウントには多要素認証が必要です。教師、コーディネーター、ITスタッフ全員がMFAを使用して生徒データにアクセスします。

🔒

学校ごとの暗号化

各学校のデータは固有のキーで暗号化されます。貴校の情報は保護され、他の学校から分離されています。

🛡️

セッション保護

複数のセキュリティ層が不正アクセスを防止します。不審な活動は自動的に保護措置を起動します。

🚫

データ販売なし

生徒データを販売、レンタル、取引することはありません。絶対に。広告パートナーなし、データブローカーなし、例外なし。

🤖

責任あるAI利用

AIチューターの改善にインタラクションパターンを使用する場合、データは完全に匿名化されます。オプトアウトも可能です。

📋

完全な監査証跡

管理アクションはタイムスタンプ付きで記録されます。完全な説明責任、リクエストに応じてレビュー可能。

規制遵守

🇬🇧🇪🇺

GDPR

英国GDPRおよびEU一般データ保護規則に完全準拠。貴校がデータ管理者であり、当社は貴校に代わってのみデータを処理します。

🇺🇸

FERPA

FERPA準拠。教育記録は保護され、承認された当事者のみがアクセスできます。

🎓

COPPA

13歳未満のユーザー向けCOPPA準拠。保護者/学校の同意が必要。若い学習者への保護強化。

🇨🇦

PIPEDA

カナダの機関向けにカナダPIPEDA準拠。

収集するデータ

透明性が重要です。システムを通過するデータは以下の通りです：

📚 学習データ

  • 実験アクション - 生徒がバーチャルラボで行うこと
  • 進捗マーカー - 完了した実験、費やした時間
  • 評価回答 - ラボの質問への回答
  • 安全コンプライアンス - 適切な手順が守られたかどうか

👤 アカウントデータ

  • ユーザー名 - 匿名可（学生IDで可）
  • 学校/クラス所属 - どの機関とグループ
  • 役割 - 生徒、教師、または管理者

🚫 収集しないデータ

住所、電話番号、生体データ、閲覧履歴、SNS情報、財務情報、健康情報、広告プロファイル

セキュリティアーキテクチャ

🔐

暗号化

転送中および保存中のデータを暗号化。生徒の作業はあらゆる段階で保護されています。

🔑

ロールベースアクセス

生徒は自分のデータのみ閲覧。教師は自分のクラスのみ。管理者は自分の機関のみ。

📝

監査ログ

管理アクションはログに記録され監査可能。すべてのデータエクスポート、すべての権限変更。

💾

安全なバックアップ

テスト済み復元手順による自動暗号化バックアップ。

🌐

オフライン機能

プラットフォームはオフラインで動作。オフライン時、再接続までデータはデバイスから出ません。

異なる設計思想

最近のEdTech大規模侵害で数百万の生徒記録が露出しました。WhimsyLabsは一般的な脆弱性を回避するよう設計されています。

✓管理アクセスには多要素認証が必要
✓学校ごとの暗号化キーで問題発生時の影響を限定
✓すべての学校データを含む集中データベースなし
✓データは第三者に販売・共有されません
✓リクエストに応じて完全な監査証跡を提供
✓常にデータ管理者はお客様です

貴校の権利

📤 データエクスポート

いつでも標準形式で貴校の全データの完全なエクスポートをリクエストできます。

🗑️ データ削除

プラットフォームを離れる際に貴校のデータの完全な削除をリクエストできます。

🔍 データアクセス

生徒に関して保持しているデータを正確に確認できます。完全な透明性。

✏️ データ訂正

不正確なデータを訂正できます。情報の管理を維持します。
