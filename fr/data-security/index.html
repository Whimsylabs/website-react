🛡️ Architecture Confidentialité d'Abord

Les Données de Vos Étudiants. Votre Contrôle.

Notre logiciel de virtual lab est conçu avec la confidentialité au cœur. Les données de votre établissement restent protégées, chiffrées et sous votre contrôle.

Nos Engagements de Sécurité

🔐

Authentification Multifacteur

Les comptes administratifs nécessitent une authentification multifacteur. Enseignants, coordinateurs et personnel informatique utilisent tous le MFA.

🔒

Chiffrement par École

Les données de chaque école sont chiffrées avec des clés uniques. Les informations de votre établissement restent protégées et séparées.

🛡️

Protection de Session

Plusieurs couches de sécurité de session empêchent les accès non autorisés. L'activité suspecte déclenche des mesures de protection automatiques.

🚫

Aucune Vente de Données

Nous ne vendons, louons ni échangeons les données étudiantes. Jamais. Aucun partenaire publicitaire, aucun courtier en données, aucune exception.

🤖

Utilisation Responsable de l'IA

Si nous utilisons des modèles d'interaction pour améliorer notre tuteur IA, les données sont entièrement anonymisées. Vous pouvez vous désinscrire.

📋

Piste d'Audit Complète

Les actions administratives sont enregistrées avec horodatage. Responsabilité totale, disponible pour révision sur demande.

Conformité Réglementaire

🇬🇧🇪🇺

GDPR

Conformité totale avec le RGPD britannique et européen. Votre établissement est le responsable du traitement; nous traitons les données uniquement en votre nom.

🇺🇸

FERPA

Conforme à la loi FERPA. Les dossiers éducatifs sont protégés et accessibles uniquement aux parties autorisées.

🎓

COPPA

Conformité COPPA pour les utilisateurs de moins de 13 ans. Consentement parental/scolaire requis; protections renforcées pour les jeunes apprenants.

🇨🇦

PIPEDA

Conforme à la loi canadienne PIPEDA pour les établissements canadiens.

Ce Que Nous Collectons

La transparence compte. Voici les données qui transitent par nos systèmes:

📚 Données d'Apprentissage

  • Actions d'expérience - Ce que les étudiants font dans le laboratoire virtuel
  • Marqueurs de progression - Quelles expériences terminées, temps passé
  • Réponses d'évaluation - Réponses aux questions de laboratoire
  • Conformité sécurité - Si les procédures appropriées ont été suivies

👤 Données de Compte

  • Nom d'utilisateur - Peut être pseudonyme (les IDs étudiants fonctionnent)
  • Association école/classe - Quel établissement et groupe
  • Rôle - Étudiant, enseignant ou administrateur

🚫 Ce Que Nous Ne Collectons Pas

Adresses, téléphones, données biométriques, historique de navigation, réseaux sociaux, infos financières, infos de santé, profils publicitaires

Architecture de Sécurité

🔐

Chiffrement

Données chiffrées en transit et au repos. Le travail de vos étudiants est protégé à chaque étape.

🔑

Accès Basé sur les Rôles

Les étudiants voient uniquement leurs données. Les enseignants voient uniquement leurs classes. Les administrateurs voient uniquement leur établissement.

📝

Journalisation d'Audit

Les actions administratives sont enregistrées et auditables. Chaque export de données, chaque changement de permission.

💾

Sauvegardes Sécurisées

Sauvegardes chiffrées automatisées avec procédures de restauration testées.

🌐

Capacité Hors Ligne

La plateforme fonctionne hors ligne. Hors ligne, aucune donnée ne quitte l'appareil jusqu'à la reconnexion.

Conçu Différemment

Des violations récentes très médiatisées dans l'EdTech ont exposé des millions de dossiers étudiants. Nous avons conçu WhimsyLabs pour éviter les vulnérabilités courantes.

✓Authentification multifacteur requise pour l'accès administratif
✓Les clés de chiffrement par école limitent l'exposition en cas de problème
✓Pas de base de données centralisée contenant les données de toutes les écoles
✓Vos données ne sont jamais vendues ni partagées avec des tiers
✓Piste d'audit complète disponible sur demande
✓Vous restez le responsable du traitement des données en permanence

Droits de Votre Établissement

📤 Export de Données

Demandez un export complet de toutes les données de votre établissement à tout moment, dans des formats standards.

🗑️ Suppression de Données

Demandez la suppression complète des données de votre établissement lorsque vous quittez la plateforme.

🔍 Accès aux Données

Examinez exactement quelles données nous détenons sur vos étudiants. Transparence totale.

✏️ Correction de Données

Corrigez toute donnée inexacte. Vous gardez le contrôle sur vos informations.

Questions sur la Sécurité des Données?

Nous sommes heureux de discuter de nos pratiques de sécurité avec votre équipe informatique ou de remplir des questionnaires de sécurité.
